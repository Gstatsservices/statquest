# StatQuest

A free, mobile-friendly statistics game website built with plain HTML, CSS and JavaScript.

## Included games

1. Descriptive Dash — mean, median and mode
2. Probability Lab — coins, dice, cards and complements
3. Distribution Detective — Binomial, Poisson, Normal, Uniform, Exponential
4. Outlier Hunter — identify suspicious observations
5. Correlation Explorer — interpret scatterplots

## Features

- Beginner, Intermediate and Advanced modes
- Score and streak system
- Best score saved locally in the browser
- No login and no database required
- Responsive design for phones, tablets and desktops
- No external libraries

## Run locally

Open `index.html` in a browser.

## Publish free

### Vercel
Create a new Vercel project and upload this folder. The site can use a free `*.vercel.app` address.

### GitHub Pages
Upload these files to a GitHub repository and enable Pages from the repository settings.

### Netlify
Drag and drop the folder into Netlify's deploy interface.

You can later connect a custom domain if you own one.
